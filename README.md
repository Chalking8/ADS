# ADS
Solar powered clap-controlled smart door closer.
ADS — Acoustic Door System

Overview

ADS (Acoustic Door System) is a solar-powered smart door closer that closes a door only when commanded by sound, such as a clap.

Unlike traditional automatic door closers that constantly force doors shut, ADS keeps the door open normally and only activates when needed.

This project was inspired by a real-life problem in my house where doors are often left open because of a magnetic stopper, and existing door closers were too annoying for daily use.

---

Features

- Clap-controlled closing
- Solar powered
- Rechargeable battery system
- Smart motorized closing
- Manual door usage still possible
- Low power consumption

---

How It Works

1. Door remains open normally
2. User claps
3. Sound sensor detects clap pattern
4. ESP32 activates motor
5. Motor pulls door closed
6. Limit switch stops the motor safely

---

Components

- ESP32 (38-pin)
- Sound sensor module
- High torque geared DC motor
- L298N motor driver
- 3x 18650 batteries
- 3S BMS module
- Solar panel
- Limit switch
- Pulley + nylon string mechanism
